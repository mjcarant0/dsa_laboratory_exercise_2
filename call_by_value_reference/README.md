# Call by Value and Call by Reference

</div>

---

## Factorial Calculator

### About

This program computes the factorial of a given non-negative integer. It uses a user-defined function that updates the result by reference, demonstrating the concept of call by value and call by reference in Python. Input validation ensures that only valid non-negative integers are accepted from the user.

---

## Line Character Overload

### About

This program demonstrates function overloading by defining a function named `linechar` that prints a line of characters. The function can be called with different arguments to print a default line, a line of a specific character, a line of a specific length, or a line with both a specific character and length.

---

## Simple Calculator

### About

This program performs basic arithmetic operations—addition, subtraction, multiplication, and division—on two integers. It uses user-defined functions to accept input values and perform the calculations. Input validation ensures only valid integers are processed, and division by zero is handled gracefully.

### Summary
- Each program demonstrates a specific concept in user-defined functions, input validation, and function overloading.
- The solutions are modular, with clear separation between input handling, processing, and output.
- These exercises reinforce fundamental programming skills in Python.
