## Add Numbers

### About

This program demonstrates function overloading by providing multiple ways to add numbers. The `add` function can handle two, three, or four numbers, with the four-number version accepting an array as input. Input validation ensures that only valid integers are accepted, and the program guides the user to enter the correct number of values for each operation.

---

## Substring

### About

This program overloads a function named `substring` to extract and display different parts of a string. The function can display the entire string, a substring starting from a given index, or a substring between two specified indices. Input validation ensures that the user provides valid indices within the bounds of the string.
