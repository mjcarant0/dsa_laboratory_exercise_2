## Sum of Odd Numbers

### About

This program prompts the user to enter ten numbers, stores them in an array, and calculates the sum of all odd numbers in the array. The array is passed as an argument to a function that processes and sums the odd values. Input validation ensures that only valid integers are accepted from the user.

---

### Summary
- Demonstrates passing arrays (lists) as arguments to functions in Python.
- Reinforces array processing and input validation concepts.
- Provides clear output showing the entered numbers, the odd numbers, and their sum.
