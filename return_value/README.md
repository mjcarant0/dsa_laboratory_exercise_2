## Area Calculator

### About

This program computes the area of various geometric shapes: square, rectangle, triangle, and circle. Each calculation is performed using a user-defined function that returns the computed area. The program validates user input to ensure only positive numeric values are accepted for dimensions, and guides the user through selecting the shape and entering the required measurements.

---

### Summary
- Demonstrates the use of user-defined functions that return values in Python.
- Reinforces input validation and modular program structure.
- Provides a menu-driven interface for calculating areas of different shapes.
