## Simple Math Operations

### About

This program performs basic arithmetic operations—addition, subtraction, multiplication, and division—on two integers. Each operation is implemented as a user-defined void function (a function that prints the result directly rather than returning it). The program includes input validation to ensure only valid integers are accepted and handles division by zero gracefully.

---

### Summary
- Demonstrates the use of user-defined void functions in Python.
- Reinforces input validation and modular programming practices.
- Provides a simple, menu-driven interface for performing arithmetic operations.
